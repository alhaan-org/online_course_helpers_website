## Online Course Helpers Website

> Built on Custom HTML, CSS and Javascript (JQuery Plugin) , OwlCarousel and Swiper.js for Plugins and Bootstrap. Using PHP for serving the website

# To run the local server for development, follow these instructions:

* Install XAMPP Server on your PC
* Navigate to the project directory
* Run the Server and see the localhost server running on your browser, woohoo!
* Make changes, do development, tweak CSS if needed!

> NOTE: This Website is configured for Nginx Server, if you want to change it to Apache2, You have to include .htaccess file in the root directory.
